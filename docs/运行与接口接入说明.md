# 运行与接口接入说明

## 使用入口

先完成数据库初始化和前后端启动。登录后可从工作台进入六个业务模块。数据库、模型和工程服务密钥仅由后端读取；浏览器使用有效期8小时的访问令牌，保存在当前浏览器会话中。

当前工作空间共享业务数据。管理员可管理账户与审计，工程师可执行工程业务，查看者只可查询与检索。当前版本尚不提供组织或项目级数据隔离。

## 知识中心

实体包含类型、名称、别名、属性、说明和来源；关系包含有向起止实体、类型、属性和来源；知识文档包含正文、来源、关联实体与版本。

知识包使用JSON：

```json
{
  "entities": [
    {"name":"示例材料","kind":"材料","source":"资料名称 v1","description":"材料说明"},
    {"name":"示例零件","kind":"零件","source":"资料名称 v1"}
  ],
  "relations": [
    {"source_key":"零件:示例零件","target_key":"材料:示例材料","kind":"材料","source":"资料名称 v1"}
  ],
  "documents": [
    {"title":"示例工艺资料","content":"工艺资料正文。","source":"资料名称 v1","entity_keys":["零件:示例零件"]}
  ]
}
```

实体按名称和类型去重；相同起止实体、类型及来源的关系去重；相同标题、来源、正文的文档去重。导入在单次事务内完成，任何无效引用均使本次导入回滚。导出的知识包可重新导入，并保留文档与实体的关联。

检索采用英文词项和中文双字片段余弦相似度、实体链接及图邻域扩展。返回文档及关系的证据编号、来源、路径和受长度限制的上下文。当前实现面向中小规模知识集：检索最多扫描5000个实体/文档、20000条关系，图谱页面最多展示500个实体。未实现外部嵌入模型或大型图数据库索引。

多跳路径使用有界广度优先搜索，避免节点重复；最多返回20条路径，最大扩展10000次，截断时返回 `truncated`。

## 任务解析与协同推理

`POST /api/v1/hybrid-reasoning/parse` 解析任务目标、交付物、所需能力与明确描述的工艺/测量参数。当前解析器使用工业字段规则，显式JSON参数优先于文本提取值。

`POST /api/v1/hybrid-reasoning/context` 预览结构化任务及检索上下文；`POST /runs` 执行候选生成。模板模式按可复现工艺或诊断模板组织候选；外部模式将来源证据注入已配置的大语言模型服务。候选包含参数、依据引用、动作及验证报告。

外部服务配置：

```dotenv
MODEL_BASE_URL=https://your-model-service.example/v1
MODEL_API_KEY=your_service_key
MODEL_NAME=your_deployed_model_identifier
MODEL_API_VERSION=chat-completions
```

服务需支持 `POST {MODEL_BASE_URL}/chat/completions`，请求包含 `model`、`messages`、`temperature`、`max_tokens` 和 `response_format`。配置的模型标识和接口版本随运行记录保存。响应内容须为JSON：

```json
{"candidates":[{"name":"方案名称","description":"方案说明","parameters":{"spindle_speed":3200,"feed_rate":600,"cut_depth":0.3,"tool_diameter":8},"evidence_ids":["实际提供的证据编号"],"actions":["工程动作"]}]}
```

候选数量1至5个。非法结构、未知引用、调用失败或超时会返回错误，不自动切换成模板结果。尚未配置或联调真实模型供应商，服务版本以实际部署标识为准。

修正接口为 `POST /runs/{id}/correct`，创建新运行并记录前次运行编号，保留各次运行的证据与候选快照。

## 约束验证

规则支持 `between`、`lte`、`gte`、`eq`、`in` 和 `required`。规则更新递增版本；报告保存实际使用的规则版本和检查结果。硬约束失败返回 `failed`，缺参数或缺资源能力返回 `unknown`，全部硬约束通过才返回 `passed`。

`units`用于显式声明参数单位。当前支持m/mm、m/s与mm/s、Hz/rpm换算；其他不匹配单位返回失败。资源约束使用换算后的值比较，避免单位导致错误放行。

语义检查通过 `semantic_constraints` 指定：

```json
{
  "scope":"cam",
  "parameters":{"spindle_speed":3200,"feed_rate":600,"cut_depth":0.3,"tool_diameter":8},
  "semantic_constraints":{
    "entities":[{"entity_id":"图谱实体编号","expected_kind":"材料"}],
    "relations":[{"source_id":"起点编号","target_id":"终点编号","kind":"材料"}]
  }
}
```

该检查验证实体类型与实际有向关系，不包含未登记领域本体的自动定理证明。PHM测量有效性通过不等于故障确诊；CAM参数范围通过不等于几何仿真通过。

## Agent与任务编排

Agent登记名称、版本、能力标签、协议及地址，可按能力查询。当前内置执行动作：`knowledge.search`、`reasoning.generate`、`constraints.validate`、`resources.list`、`cam.plan`、`phm.diagnose`。

流程节点定义 `id`、`action`、`depends_on` 和 `input`。输入支持 `{"$ref":"context.query"}` 和 `{"$ref":"nodes.search.evidence"}`。运行时保存完整节点定义和版本快照；循环依赖、未知动作与不存在的依赖会在提交前拒绝。

执行器按拓扑顺序运行节点，保存逐节点结果与事件。验证节点未通过时停止后续节点。幂等键以提交人隔离，相同键与相同请求返回原任务，不同请求返回409。取消在节点边界生效，不撤销已完成的外部调用。

当前执行器为单进程后台任务实现，启动时将中断的运行标记为失败，避免把未完成作业显示成成功。运行使用单个worker；不支持多进程抢占、自动断点恢复、并行节点执行或分布式补偿。

### MCP接口

端点 `/mcp`，协议版本 `2025-06-18`，采用无状态Streamable HTTP的JSON响应方式。客户端带 `Authorization: Bearer <token>`，后续请求带 `MCP-Protocol-Version: 2025-06-18`。

支持 `initialize`、`ping`、`tools/list`、`tools/call` 和通知接收。工具为 `knowledge_search`、`constraints_validate`、`resources_list`；写入型验证工具受角色限制。GET和DELETE返回405，无会话ID、SSE订阅或工具列表动态通知。

### A2A接口

能力卡位于 `/.well-known/agent-card.json`，JSON-RPC端点为 `/a2a`。实现0.3.0协议子集：`message/send`、`tasks/get`、`tasks/cancel`，采用非阻塞任务提交和轮询，产物使用DataPart。暂不支持流式消息、推送、长会话与远程Agent自动代理执行。

发送示例：

```json
{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"kind":"message","messageId":"调用方唯一消息编号","role":"user","parts":[{"kind":"text","text":"TC4叶盘加工工艺规划"}]}}}
```

默认执行示例协同流程，也可通过 `params.metadata.workflow_id` 指定已有流程，并通过 `params.metadata.context` 提供该流程需要的输入。任务查询和取消检查提交人或管理员身份。

协议参考：[MCP传输规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[A2A 0.3.0规范](https://a2a-protocol.org/v0.3.0/specification/)。

## 叶盘CAM

先上传几何文件，再创建项目并选择资源、材料和工艺参数。规划接口组织工序、检索依据、切削速度及约束报告。

本地参数比选采用有界网格搜索，检查转速、进给、切深、刀径与资源能力；以给定径向切宽的理想材料去除率 `进给×切深×切宽` 排序。该指标不含切削力、颤振或几何约束，不自动替换项目参数。

真实工程服务配置 `CAM_SERVICE_URL` 与 `CAM_SERVICE_TOKEN`，适配器调用：

| 操作路径 | 输入要点 | 必须返回的字段 |
| --- | --- | --- |
| `/algorithm` | 项目、径向切宽、input_digest | success、input_digest、algorithm_version、candidates |
| `/toolpath` | 项目、几何file_id/sha256/download_url、input_digest | success、input_digest、artifact_id、software_version |
| `/simulate` | 项目、当前刀路、input_digest | success、input_digest、collision_free、constraint_passed、program、software_version |
| `/dispatch` | 项目、目标资源、程序、幂等键、input_digest | success、input_digest、accepted、receipt_id |

所有响应必须匹配当前项目输入摘要。几何下载接口受平台令牌保护，适配器部署方需为工程服务配置独立的受控访问方式；下载URL为平台相对路径，不能当成本地文件路径。

当前仓库提供公开接口调用、状态判断及流程代码，不包含商业CAM软件、几何内核、机床控制器或其许可证。工程服务应实现真实刀路生成、仿真及后处理。生产分发由平台审核后触发，服务侧应依据幂等键避免重复发送。

演示模式没有制造刀路、数控程序或碰撞仿真结果；因此不会得到工程放行状态。真实服务通过后依次执行审核、分发及现场反馈，质量未通过时进入待复核。

## 数控机床PHM

设备配置振动与温度阈值，采样时间使用带时区ISO格式。采样按UTC归一、时间排序和同时间点合并；保留最近10000点。最新采样超限时生成异常事件，后续使用知识检索、候选生成和测量规则组织分析。

RUL接口用实际时间间隔拟合振动有效值的线性趋势，计算达到配置失效阈值的剩余小时数，并返回拟合度、时间基准、方法版本和输入点数。少于5点、无上升趋势或拟合度不足时不返回寿命估计。此实现无需外部预测依赖，但不是经现场验证的RUL模型，也不提供概率区间。

维护工单需在候选分析后创建，按“待执行→处理中→已完成”转换。完成时必须提交实际故障、维护措施和复测结果，关联异常事件随后关闭。反馈不会未经审核自动写回知识库；知识工程师可据此修改文档并生成新版本。

## 当前工程边界

文件采用本地存储和SHA256校验，单文件20MB。工作流和报告支持JSON导出。通用任务采用页面轮询；尚未引入站内通知、分布式队列、对象存储、SSE订阅、大规模向量索引或高级三维刀路显示。

这些边界与具体第三方接入条件均保留在运行配置和接口说明中，避免将模板、测试夹具或趋势外推误当作真实工程计算结果。
