# 容器部署

当前本地开发已使用现有MySQL时，无需运行容器数据库。以下配置用于独立部署环境，不复用本地业务库。

1. 复制 `deploy/.env.example` 为 `deploy/.env`，填写随机密码和密钥。MySQL密码建议使用随机十六进制字符串，避免连接URL的特殊字符编码问题。
2. 在deploy目录执行 `docker compose --env-file .env -f compose.yml up -d --build`。
3. 打开 `http://127.0.0.1:8080`；接口文档使用 `http://127.0.0.1:8001/docs`。

服务包含MySQL 8.4、单进程后端和Nginx前端。数据库端口使用3307，避免与现有3306服务冲突；文件和数据库使用命名卷保存。

后端启动时执行迁移并创建管理员，`SEED_DEMO=true` 时导入示例数据。构建上下文排除本地环境凭据、虚拟环境及文件存储目录。

使用 `docker compose --env-file .env -f compose.yml down` 停止服务。数据库与文件卷保留；删除卷会删除数据，应按部署方备份策略处理。

此配置尚未执行容器镜像构建验证。面向公网部署时需配置域名、HTTPS、受控网关和数据库备份；当前默认端口仅绑定本地回环地址。
